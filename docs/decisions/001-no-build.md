# ADR-001. Без сборки и внешних зависимостей

Статус: принято 20.10.2026, подтверждено 14.11.2026.

## Контекст
Сайт должен открываться двойным щелчком по `index.html`, публиковаться на GitHub Pages и работать без сервера. Заказчик не программирует; каждая зависимость — это то, что он не сможет починить сам.

## Решение
Обычные `<script>`-теги в порядке зависимостей, один глобальный объект `Seshat*` на файл, `module.exports` для Node. Никаких сборщиков, транспиляторов, пакетов из npm в рантайме. Единственная библиотека — KaTeX, локальной копией в `assets/katex/`. Кэш браузера сбрасывается параметром `?v=версия` (тест `release.test.js`).

## Последствия
- Плюс: ноль инфраструктуры, сайт живёт на любом статическом хостинге и на флешке.
- Минус: нет модулей ES, типов, автоматической проверки стиля; порядок подключения скриптов — ручной. Компенсируется тестами в Node и правилами AGENTS.md п. 16, 23, 24.
- Пересмотр: когда появится сервер (этап 4), серверный код может использовать зависимости; клиентская часть открытого слоя остаётся без сборки.
