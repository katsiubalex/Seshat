# ADR-011. Распознанные тексты хранятся постоянно

Статус: принято 14.11.2026. Правило постоянное: отменяется только новым решением заказчика.

## Контекст
Распознавание сканов занимает часы машинного времени. 14.11.2026 выяснилось, что постраничные результаты распознавания трёх учебников лежали только во временной рабочей среде сессии: в репозитории были собранные из них главы, а первичный слой пропал бы вместе с сессией.

## Решение
1. **Распознанный текст не теряется никогда.** Постраничный результат распознавания сохраняется в репозитории источников в том же изменении, что и собранный из него текст: для книг — `учебники/текст/<книга>/_страницы/p-<N>.txt`, для норм — рядом с Markdown.
2. **Работа с источником не считается законченной, пока распознанное не отправлено в репозиторий.** Держать результат только в рабочей среде запрещено. Если сессия прерывается, первым делом отправляется уже распознанное.
3. **Главы собираются из постраничных файлов скриптом** (`tools/book2md.py --txtdir`), а не правятся вручную: исправление вносится в постраничный файл или в карту глав, затем сборка повторяется.
4. **Проверка автоматическая**: `tools/check_repo.py` в репозитории источников запускается при каждой отправке и не пропускает книгу с распознанным текстом без папки `_страницы/`.

## Последствия
- Репозиторий источников растёт на несколько мегабайт на книгу — приемлемо.
- Пересборка книги с другим делением на главы занимает секунды, а не часы.
- То же правило распространяется на любой дорогой промежуточный результат (ручная сверка, набранные формулы): он сохраняется сразу, а не «в конце».
