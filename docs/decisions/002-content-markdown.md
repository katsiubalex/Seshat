# ADR-002. Контент в Markdown-файлах

Статус: принято 23.10.2026.

## Контекст
Статьи лежали внутри JS. Кураторы и рецензенты не должны трогать код; нужна история правок по статьям и редактор без Git.

## Решение
Одна статья — один файл `content/<коллекция>/<id>.md` с паспортом (front matter, подмножество YAML, разбор в `js/mdcontent.js`). Сборка `node tools/build-content.js` → `js/content.js`, который сайт читает. Коммитятся и источники, и результат. Редактирование: Sveltia CMS (`admin/`), редактор на сайте (PR через API GitHub), GitHub напрямую.

## Последствия
- `js/content.js` руками не правится (AGENTS.md п. 15).
- Схема коллекции — `COLLECTIONS` в `mdcontent.js`; новая коллекция = запись там + тест.
- Следующий шаг (этап 1): перевести `docs.js` в `content/docs/*.md` тем же способом.
