# Месячные отчёты

Один файл на месяц: `ГГГГ-ММ.md`. Пишется в первую сессию следующего месяца по шаблону ниже; числа — из `npm run metrics`, посещаемость — из аналитики, задачи — с доски GitHub. Карта состояния — шесть направлений по шкале 0–4 (смысл уровней — в документе аудита от 13.11.2026).

```markdown
# «Сешат» — отчёт за <месяц год>

Этап дорожной карты: <N · название>. Версия: <x.y.z>. Сессий за месяц: <n>.

## Одним абзацем
Что изменилось по сути и насколько ближе ворота этапа.

## Карта состояния (0–4, стрелка — изменение за месяц)
Расчётное ядро <n> · База знаний <n> · Нормативка <n> · Обучение <n> · Сообщество <n> · Проф. слой <n>

## Числа (было → стало)
| Число | Прошлый месяц | Этот месяц |
|---|---|---|
| … | | |

## Сделано
- версии и что в них (из CHANGELOG)

## Решения месяца
- что решили и почему (ссылки на Issue / ADR)

## Не сделано и почему

## Нужна помощь
- источники, люди, решения, которые зависят не от автора

## Цели на следующий месяц
- не больше трёх, каждая с проверяемым результатом
```
