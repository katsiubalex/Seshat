# Дорожная карта «Сешат»

Пять этапов. Переход — только по критериям выхода («ворота»), не по календарю. Объём — в рабочих сессиях (одна сессия — 2–4 часа заказчика с агентом). Полное обоснование — в документе аудита от 13.11.2026; месячные отчёты — `docs/reports/`.

**Текущее положение: 14.11.2026 — конец этапа 0, вход в этап 1.** Версия 0.52.0.

## Инварианты (не нарушаются ни на одном этапе)

1. Открытое ядро бесплатно навсегда (CC BY-SA); деньги только в профессиональном слое.
2. Каждый расчёт прозрачен: число → формула → пункт нормы → источник.
3. Нейтральность каталогов; спонсорство и конфликт интересов помечены.
4. Знание живёт в людях: кураторы и рецензенты работают без Git и без программирования.
