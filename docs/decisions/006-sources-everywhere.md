# ADR-006. Источник у каждого числа

Статус: принято 14.11.2026 (практика с 0.36.0).

## Контекст
Миссия платформы — прозрачное инженерное знание. Статьи и коэффициенты писались с помощью ИИ, который умеет выдавать правдоподобные числа без источника. Доверие технолога теряется с первого неверного коэффициента.

## Решение
Каждое число, формула и факт — с источником (пункт нормы, страница издания, расчёт). Отсутствие источника помечается явно и единообразно: в статьях `[^?]`, в коде `EST` / комментарий `// оценка`, на сайте `≈`. Тест `content.test.js` требует сноску у каждого абзаца. Долг по источникам считается метрикой (`tools/metrics.js`) и закрывается рецензентами. Удалять пометку, не найдя источник, запрещено (AGENTS.md п. 7 раздела «никогда»).

## Последствия
Статьи пишутся медленнее. Это цена, которую проект платит сознательно.
