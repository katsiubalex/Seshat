# ADR-004. Сервер и аккаунты — не раньше этапа 4

Статус: принято 14.11.2026.

## Контекст
Один автор, ноль внешних участников, ноль измеренных пользователей. Сервер требует денег, администрирования и соблюдения 152-ФЗ. Ни одна функция открытого слоя без сервера не невозможна: библиотека хранится в localStorage с выгрузкой в JSON, правки идут через GitHub.

## Решение
До ворот этапа 3 (см. ROADMAP) — только статика на GitHub Pages (+ зеркало и свой домен). Исключения, не требующие своего сервера: аналитика без куки на стороннем сервисе; маленькая функция-прокси OAuth для Sveltia CMS (этап 3). Сервер появляется вместе с первой платной функцией и первым платящим партнёром.

## Последствия
- Расчётное ядро обязано работать в Node уже сейчас (AGENTS.md п. 16) — это и есть подготовка к серверу.
- JSON проекта — контракт (ADR-005): его будет хранить сервер.
- Оракул «Сешат» остаётся на правилах; языковая модель — вместе с сервером.
