# Seshat — конструктор очистных сооружений НДТ

Веб-приложение для подбора схем очистки сточных вод из наилучших доступных технологий (НДТ).
Пользователь задаёт состав стоков, собирает схему из каталога технологий и видит концентрации
загрязнений после каждой ступени в сравнении с нормативами.

## Возможности

- ввод расхода и 9 показателей: ВВ, БПК₅, ХПК, азот аммонийный, нитритов и нитратов, фосфаты, нефтепродукты, жиры;
- каталог из 18 технологий: механическая и биологическая очистка, доочистка, обеззараживание;
- изменение порядка ступеней и их эффективности;
- проверки применимости (нехватка органики для денитрификации, нефтепродукты перед биологией и др.);
- расчёт энергопотребления и количества осадка;
- нормативы: ПДК рыбохозяйственных водоёмов, примерные целевые значения или свои;
- подсказки, какие технологии добавить для невыполненных показателей;
- библиотека: кнопки «Создать профиль», «Создать схему», «Создать норматив»; свои записи можно сохранять и удалять, примеры остаются неизменными; выгрузка и загрузка библиотеки файлом.

Сохранённое хранится в браузере пользователя (localStorage), аккаунт не нужен. Чтобы перенести библиотеку
на другой компьютер или передать коллеге, её выгружают в JSON-файл и загружают там.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `css/style.css` | оформление, светлая и тёмная темы |
| `js/data.js` | показатели, каталог технологий, примеры стоков, нормативы |
| `js/model.js` | расчётная модель (чистые функции) |
| `js/store.js` | библиотека пользователя: сохранение, проверка данных, выгрузка и загрузка |
| `js/app.js` | интерфейс |
| `tests/model.test.js` | тесты модели |
| `tests/store.test.js` | тесты библиотеки |
| `tests/release.test.js` | проверка номеров версий у подключённых файлов |

Сборка не нужна: сайт открывается двойным щелчком по `index.html` или публикуется через GitHub Pages.

## Выпуск новой версии

Браузеры кэшируют файлы стилей и скриптов. Чтобы после обновления все получили свежий код,
поднимите `version` в `package.json` и тот же номер в `?v=` у всех подключений в `index.html`.
Тест `tests/release.test.js` проверяет, что номера совпадают.

## Допущения модели

Модель коэффициентная: каждая ступень снижает концентрации на типовую долю. Биологические ступени
дополнительно учитывают ассимиляцию N и P илом, нитрификацию, денитрификацию с ограничением по
органике (≈ 4 мг БПК₅ на 1 мг N) и прирост ила. Это инструмент сравнения вариантов, а не замена
расчёта по моделям ASM/ADM.

Эффективности технологий взяты из типовых литературных диапазонов и подлежат сверке с ИТС 10
«Очистка сточных вод с использованием централизованных систем водоотведения поселений, городских округов».
