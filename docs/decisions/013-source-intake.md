# ADR-013. Порядок приёмки источников: распознавание и упаковка информационного базиса

Статус: принято 16.11.2026. Правило постоянное: отменяется только новым решением заказчика.

## Контекст
База источников растёт: к 15 книгам и 101 норме добавляются ещё 13 изданий, около 5400 страниц. До сих пор каждая книга принималась вручную: параметры распознавания, границы глав и смещение страниц подбирались по месту. Это дало ошибки, найденные случайно: неверные номера страниц, заголовки с искажёнными номерами параграфов, текст, оказавшийся набором букв. Проба нового порядка на учебнике Воронова и Яковлева (2006) нашла то, что вручную не было бы замечено: в скане нет пяти страниц издания, а один раздел начинается на отсутствующей странице.

## Решение
1. **Оригинал — единственный источник истины.** Скан или официальный PDF хранится неизменным; тексты, главы, описи и разметка получаются из него программой.
2. **Один рецепт — одна книга.** Все параметры приёмки записаны в файле рецепта; замена текста на лучший — повторный запуск.
3. **Два независимых чтения каждой страницы** разными способами; расхождение чисел между ними записывается постранично.
4. **Скелет книги — проверенное оглавление.** Заголовки, номера разделов и страницы берутся из него, а не из распознанного текста; каждое название программа ищет на своей странице в обоих чтениях.
5. **Ничего не теряется молча:** отсутствующие страницы скана, пропуски нумерации формул, таблиц, рисунков и пунктов, расхождения чтений записываются в отчёты рядом с текстом.
6. **Распознанной формуле и таблице не верят:** в тексте они помечены, числа и формулы берутся только из единиц знания (ADR-012).
7. **Нормы** режутся на пункты программой дословно; рабочий текст — сводная редакция (ADR-012, п. 9).
8. **Каждый раздел каждого источника** привязан к теме рубрикатора или числится без темы (ADR-010, дополнение).
9. **Источник, принятый в обход порядка, проверка не пропускает.** Книги, принятые раньше, перечислены отдельным списком и переводятся на порядок по мере использования; пополнять список нельзя.

Подробный порядок, команды и состав слоёв базы — `ПРИЁМКА.md` репозитория источников.

## Выбор способа распознавания
Испытание 16.11.2026 на 9 страницах (текст, формулы, таблицы): встроенный слой DjVu — 97,3 % известных слов, marker (surya) — 96,5 %, tesseract — 91,8 %. Ни один способ не читает формулы надёжно. Правило: основное чтение — встроенный слой, если он не хуже 93 %, иначе marker; второе чтение — tesseract по изображениям страниц.

## Последствия
- Приёмка книги — несколько команд и один файл рецепта; ручной остаётся только сверка неподтверждённых записей оглавления по изображению.
- Объём хранения растёт: два чтения на страницу. Изображения страниц в репозитории не хранятся — они получаются из оригинала.
- Крупные оригиналы должны храниться не в одном месте: потеря оригинала делает перераспознавание невозможным.
- Ошибки распознавания не исчезают; порядок делает их видимыми и исправимыми повторным запуском.
