# ADR-005. JSON проекта — контракт

Статус: принято 14.11.2026.

## Контекст
Схема станции, сеть, схема водоподготовки, профили стоков и нормативы хранятся в браузере пользователя (`store.js`, `VERSION = 1`, миграции `migrateSteps`). Тот же формат будет храниться на сервере и кормить генератор документации (этап 4). Потеря сохранённых данных пользователя недопустима.

## Решение
Формат сохранённых данных — публичный контракт. Любое изменение: `VERSION += 1`, функция миграции со старого формата, тест миграции на реальном сохранённом примере (файл в `tests/fixtures/`). `id` сооружений, процессов, показателей, документов, статей не переименовываются (AGENTS.md п. 13–14). Заложить в схему поле `products: []` у ступени — список конкретных изделий (этап 3–4), пока пустой.

## Последствия
Медленнее менять структуру данных; зато выгрузка пользователя 2026 года откроется в 2028-м, а серверная миграция сведётся к той же функции.
